# 《琵琶曲》双角色二创

本期原片还原版的验收进度、在途队列和接手步骤见[制作交接](pipa-production-handoff.md)。

此处《琵琶曲》指短视频平台的双角色二创。常见作品让两位角色演绎夸张的对峙，并用郑浩、冰洁的同名歌曲安排剪辑节奏。传播中使用的动画素材源自 Kotte Animation 的《Russian Roulette》。 [动画原作](https://www.youtube.com/watch?v=S8Z3gGqc7W4) · [歌曲发行版](https://www.youtube.com/watch?v=zjJjagEEUG4)

当前案例为「神隐黑炎 vs 虚人梦」。两张独立的全身图采用相近身高、头身比和身材，可作为后续两位角色的外观参考。 [案例与两张入库概念图](../series/pipa/versus/episodes/01-shenyin-heiyan-vs-xuren-meng/README.md)

用户指定「成都超人 p01 原曲」作为重点分镜和配乐参考。原动画提供动作与镜头出处，两张概念图提供角色造型。 [原动画素材](https://www.bilibili.com/video/BV1pvY16QEwd/) · [分镜与 BGM 参考](https://www.bilibili.com/video/BV14BeA6CEUb/)
