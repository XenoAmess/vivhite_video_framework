## 音乐的整体设计

听感目标是轻盈、安静、有向前行走的节奏，同时给旅行画面留出空间。持续的和弦铺底负责连贯，轻拨弦琶音负责流动，较高的钟铃旋律提供可辨认的主题；低音和很轻的噪声敲击在部分段落加入，再在开阔与收尾段减少。

这里的“拨弦”“钟铃”“铺底”是程序合成的音色名称，不是录制的真实吉他、钢琴或弦乐。听感较柔和的原因可以从实现解释：波形以正弦基音为主，较高次谐波较弱；起音有短包络，没有直接从最大振幅开始；旋律与伴奏分布在不同音区；段落之间通过音量、密度和音区变化形成呼吸。这是对配器选择的解释，不是对不同音乐工具的客观排名。

## 节拍、和声与低音

四分音符长 `60 / 96 = 0.625` 秒，一小节四拍，共 2.5 秒。一个和弦保持两小节，即 5 秒，四个和弦循环一次需要 20 秒。

| 顺序 | 和弦 | 代码中的根音 MIDI | 供铺底／琶音使用的音符 | 实际低音 MIDI |
| --- | --- | --- | --- | --- |
| 1 | Dmaj9 | 50，D3 | 62、66、69、73、76：D4、F♯4、A4、C♯5、E5 | 38，D2 |
| 2 | Aadd9 | 45，A2 | 61、64、69、71、76：C♯4、E4、A4、B4、E5 | 33，A1 |
| 3 | Bm7 | 47，B2 | 62、66、69、71、74：D4、F♯4、A4、B4、D5 | 35，B1 |
| 4 | Gmaj7 | 43，G2 | 62、66、67、71、74：D4、F♯4、G4、B4、D5 | 31，G1 |

和声骨架是 I–V–vi–IV，增加九音、七音以及相邻音区的连接，使转换不需要大幅跳动。音名采用 MIDI 60 为 C4 的约定。

铺底每小节从上述五音取前四音，同时发声，各持续 3 秒，因此与下一小节有约半秒重叠。单音增益为 `0.018 × energy`，四个声部的声像分别为 −0.33、−0.11、+0.11、+0.33。

低音从第 5 小节开始，也就是 10 秒处加入。每小节第一拍弹一次 `root - 12`，时长 1.6 秒、增益 `0.115 × energy`；多数段落第三拍再弹一次，时长 1.3 秒、增益 `0.07 × energy`。80–120 秒的疏朗段只保留第一下。

## 琶音与主题旋律

每小节的八分音符琶音按和弦音数组下标循环：

```text
0 → 2 → 1 → 3 → 2 → 1 → 3 → 4
```

音符间距 0.3125 秒，单音合成窗口为 1.25 秒，增益 `0.055 × energy`。相邻音符交替放在 +0.30 与 −0.36 的声像位置，产生轻微左右流动。80–120 秒段跳过奇数下标的八分音符位置，密度减半。

主题旋律从第 9 小节、20 秒处加入，使用 `bell` 音色，增益 `0.095 × energy`，声像 +0.08。以下为代码中 16 小节主题的完整音高与节奏骨架；每个条目为“拍内偏移：音名／节奏跨度（拍）”，拍从 0 起算。

| 主题小节 | 音符 |
| --- | --- |
| 1 | 0：D5／1；1.5：F♯5／0.5；2.5：A5／1 |
| 2 | 0：F♯5／1.5；2：E5／0.75；3：D5／0.75 |
| 3 | 0.5：C♯5／0.75；1.5：E5／1；3：A5／0.75 |
| 4 | 0：F♯5／1.5；2：E5／1.5 |
| 5 | 0：D5／1；1.5：F♯5／0.5；2.5：A5／1 |
| 6 | 0：B5／1.5；2：A5／0.75；3：F♯5／0.75 |
| 7 | 0：G5／1；1.5：F♯5／0.75；2.5：E5／0.75 |
| 8 | 0：D5／2；3：C♯5／0.75 |
| 9 | 0.5：F♯5／0.75；1.5：A5／0.75；2.5：C♯6／1 |
| 10 | 0：B5／1；1.5：A5／1；3：F♯5／0.75 |
| 11 | 0：E5／1；1.5：C♯5／0.75；2.5：E5／1 |
| 12 | 0：A5／1.5；2.5：F♯5／1 |
| 13 | 0：F♯5／1；1.5：D5／1；3：B4／0.75 |
| 14 | 0：D5／1.5；2：F♯5／1.5 |
| 15 | 0：G5／1；1.5：F♯5／0.75；2.5：E5／0.75 |
| 16 | 0：D5／2.75 |

这里的节奏跨度控制音符合成窗口，实际窗口是 `跨度 × 0.625 + 0.9` 秒；音量在窗口内按指数衰减，不会全程等响地持续这么久。旋律按当前绝对小节下标取 `melody[index % 16]`，并非到 20 秒时重新从主题第 1 小节开始。

通常每个 16 小节周期的最后一小节暂不演奏旋律，留下空隙；160–200 秒段允许该小节演奏。80–120 秒段的旋律整体降低一个八度。时间轴结束后才会开始的音符直接跳过，未结束音符按实际总时长截断，因此两个版本实际写入的音符数不同。

## 段落如何变化

`energy` 是合成前各乐器增益的倍率，不是响度单位。程序以 16 小节、40 秒为一个段落：

| 时间 | 实际安排 |
| --- | --- |
| 0–10 秒 | 和弦铺底、琶音，`energy = 0.68`；首秒总线淡入 |
| 10–20 秒 | 加入低音，保持较轻的音量 |
| 20–30 秒 | 加入钟铃主题 |
| 30–40 秒 | 再加入很轻的噪声敲击 |
| 40–80 秒 | `energy = 1.0`，较完整的配器 |
| 80–120 秒 | `energy = 0.68`；琶音减半，低音减少一次，旋律低一个八度，移除敲击 |
| 120–160 秒 | 恢复完整配器与 `energy = 1.0` |
| 160 秒以后 | 保留和声、琶音和旋律，移除敲击，形成较轻的收尾质感 |

此外，在“某小节起点晚于总时长减 12 秒”时，该小节的 `energy` 再乘 0.65。全曲最后 3 秒统一淡出。202 秒版在 200 秒处进入下一个代码段落，但只余 2 秒，且已处于结尾淡出中；196 秒版不会进入该段。

音乐按持续的节拍运行，环境声按镜头运行。没有把每个剪辑点强制对到重拍，也没有为每一个手部动作生成精准拟音。

## 音色是怎样算出来的

MIDI 音高先转换为频率：

```text
f = 440 × 2^((midi - 69) / 12)
```

在 48kHz 下，为每个音符生成局部时间数组 `t`，单位是秒，再计算基音、谐波与包络。

### 拨弦与钟铃

二者的谐波配方相同，区别是衰减速度：

```text
tone(t) = sin(2πft) + 0.28 sin(2π·2ft) + 0.09 sin(2π·3ft)
envelope(t) = (1 - exp(-140t)) × exp(-kt)
pluck：k = 4.2
bell： k = 2.2
```

短起音项减少突然起振的爆点，指数衰减使拨弦快速退去，钟铃留得更久。钟铃使用较高音区，因而与伴奏区分开；它没有使用金属打击乐采样或真实钢琴模型。

### 和弦铺底

```text
tone(t) = sin(2πft) + 0.22 sin(2π·2ft)
envelope(t) = min(t / 0.28, 1) × min((length - t) / 0.5, 1)
```

起音约 0.28 秒、尾部渐退约 0.5 秒。只有较弱的二次谐波，音色保持柔和，主要作用是把不同旅行场景连起来。

### 声像和回声

声像使用等功率关系：

```text
左声道倍率 = sqrt((1 - pan) / 2)
右声道倍率 = sqrt((1 + pan) / 2)
```

每个音符还在 0.1875 秒后向左右声道各加入原信号的 0.10，约为原始单音信号的 −20dB。它是一次简单延迟，不是卷积混响，也不是多次反馈。这个延迟没有继续沿用该音符原来的声像倍率。

### 很轻的敲击

部分段落在每小节第 1、3 拍加入 0.16 秒高斯噪声：

```text
tap(t) = normal_noise(t) × exp(-42t) × 0.009
```

它提供微弱的节拍触感，没有使用底鼓、军鼓或脚步录音，也不是逐镜同步的真实脚步声。

## 环境声怎样与画面对齐

每镜的开始样本位置直接由 `startFrame × 1600` 得到，因为 `48000 / 30 = 1600`；长度为 `seconds × 48000`。这样按整数样本定位，不会因连续拼接积累小数误差。

每镜先生成标准正态噪声，再用代码中的 480 点移动平均差分得到低频风底。实现是对左补 479 个零的噪声做累加，用相距 480 的差相减、除以 480，最后在尾部补一个零恢复长度。基础风声再乘 `0.65 + 0.35 sin(2π·0.22t)`，产生很慢的起伏。

程序读取镜头的 `soundDescription`，依次添加不同质感：

| 条件 | 附加信号与增益 |
| --- | --- |
| 默认风 | 基础风底，最终乘 0.25 |
| 包含“水／浪／溪／桨” | 加入 `noise × 0.018 × (1 + 0.6 sin(2π·0.31t))`，最终乘 0.35 |
| 包含“雨”或“檐滴” | 再加入 `noise × 0.035`，最终乘 0.38 |
| 包含“车／轮／缆” | 再加入 56Hz、112Hz 正弦，振幅分别为 0.025、0.009；沿用此前选定的增益 |

这些判断按顺序执行，可以叠加；收据中 `kind` 保存最后命中的标签，不代表只含该类声音。每镜环境声开头约 0.12 秒淡入、结尾约 0.18 秒淡出，再等量加入左右声道。

这是程序化环境质感，没有录制真实海浪、列车、风雨或滴水，也没有实现每一滴水、每一次摩擦的精确事件。导演稿里的声音描述比当前合成器的声音类别更细；收据保留原描述，不应据此声称已逐项完成拟音。

## 混音、响度和成片音轨

音乐总线与环境声总线相加后，先做首秒淡入、末尾 3 秒淡出。接着测全曲样本峰值，将峰值缩放到 0.82，写成 `soundtrack-raw.wav`。这是整体增益缩放，不是动态压缩器。

FFmpeg 随后执行：

```text
loudnorm=I=-18:TP=-1.8:LRA=8
```

目标为 −18 LUFS 综合响度、−1.8dBTP 真峰值、8 LU 响度范围，输出仍是 48kHz、16-bit PCM。当前调用是单遍 `loudnorm`；这些是处理目标，不是未经测量就能保证的最终实测值。输出后重新读取 WAV，样本数必须恰好匹配画面时间轴，否则失败。

正式影片再将这份 WAV 编码为 AAC。模型生成的原始音轨另外存档，不进入最终混音。整个配方只有振荡器和噪声，没有 TTS、歌词、演唱、哼唱或录制的人声。收据中的内部音乐说明用于制作留档，不要求将其显示到片尾。

## 随机性、复现与保留材料

`np.random.default_rng(20261116)` 提供敲击和环境声噪声。旋律音高、和声、节奏、声像和段落规则本身是确定的，随机种子并不随机作曲。音乐敲击和环境声共用同一随机序列；改变总时长、镜头数量、顺序或声音描述，可能改变后续环境声字节，即使种子相同。

本次复现环境为 CPython 3.12.6、NumPy 2.5.4、FFmpeg 8.1.1（Gyan Windows full build）。跨版本的随机实现、浮点计算或响度处理可能影响逐字节结果；需要精确恢复时保留已验证 WAV、实际版本与代码，不只记录种子。

需要重新配器时，使用Cover并开启Instrumental；只上传实际原曲比单独填写风格描述更有利于保留旋律依据。若界面提供相应高级滑杆，可从Audio Influence 90%、Weirdness 10%、Style Influence 60%起步。这是本曲的试验建议，不是官方最佳值或旋律锁定保证；Remaster的Subtle选项与Cover滑杆是不同控制，不要混为一谈。[滑杆含义](https://help.suno.com/en/articles/6141377)

Style可填写：

```text
Gentle ambient electronica, cinematic travel instrumental. Preserve the uploaded melody, chord progression, phrasing, tempo and quiet emotional arc. 96 BPM, D major, 4/4. Delicate warm plucked arpeggios, soft bell-like lead, airy pads, restrained rounded bass and very light percussion. Improve note definition, instrument separation, natural dynamics and stereo depth. Short transparent reverb, sparse arrangement, intimate atmosphere and a smooth soft ending.
```

Exclude Styles：

```text
no vocals, no humming, no choir, no heavy drums
```

歌词框不填写歌词或散文制作要求；需要内容时只使用纯器乐结构标签。排除项不能代替成品检查，输出仍需确认没有歌声、哼唱和人声，并对照原曲检查主题旋律、速度、和声、配器密度和结尾。

这两份母带含程序环境声，Remaster可以直接试用。若重新配器，建议先另导独立音乐轨，待Suno音乐定稿后再混回原环境声，避免风、车声被模型解释成乐器。当前源码尚未输出这种独立分轨；原WAV和影片继续保留，Suno输出应使用新目录。新音乐最终还需按196秒时间轴重新核对与合成，不能假定生成后恰好匹配所有镜头。
