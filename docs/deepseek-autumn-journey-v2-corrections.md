# 衍生旅行影片：完整印花与鲸尾修订

本页记录《大肥鱼／秋日旅程》v2返修的方法边界。用户反馈见[七项返修范围](../series/deepseek/autumn-journey/episodes/01-autumn-journey/production/revision-v2-requirements.md)。v1成片、审核记录和Release保留，原有“助手通过”不能覆盖后续用户指出的缺陷。具体是否采用以v2源片及成片审核记录为准。

## 脸部稳定不等于印花稳定

`stabilize_printed_patch.py`的局部圆形蒙版可以止住脸部变化，却可能让圆外身体、头发、鞋和尾巴继续活动。跟踪图案内部特征还可能把模型动画误当成载体运动，造成脸与包面错位。

新增[stabilize_carrier_plane.py](../video-maker/tools/stabilize_carrier_plane.py)处理整张原始纹理，跟踪区域显式排除完整印花，依据包缝、座椅、窗框或台面计算变换。每帧直接对首帧求正反向LK与RANSAC相似变换，不累计上一帧矩阵；记录每帧矩阵、内点数、残差、尺度及输入输出指纹。跟踪失败或超过预设运动范围就停止，不能静默固定最后一帧继续输出。

这是视频纹理合成，不能叫原画逐像素不变。相似变换不适合明显折叠、转面、透视剧变或被手遮挡的布面，遇到这些情形需要改变生成动作、采用合适表面模型或重生成，不能只提高容差。

实际候选显示，即使整张印花固定，矩形遮罩仍可能在布料上留下色块。S26第一组因此拒收，后改为保留整个原始包及印花，沿实物轮廓融合，背景道路继续运动。S43恢复整个透明板面，维持原图印花比例和可读大小；仍需检查透明处背景、反射、边缘和底座。入口为[本期带审核门的载体修订器](../series/deepseek/autumn-journey/episodes/01-autumn-journey/production/render-carrier-repairs-v2.py)。

## 动态玻璃后方不能冻结一块背景

S40第一组把贴纸旁蓝色玻璃也固定了，窗外灯带变化后就能看到贴片边缘，该候选拒收。修订路线是用imagegen去掉贴纸得到干净首帧，再用局域网模型生成空夜车背景；另外用imagegen生成完整透明RGBA纸贴。最后依据窗框定位整张纸贴，让背景灯带继续流动、贴纸自身保持固定。

[夜车合成入口](../series/deepseek/autumn-journey/episodes/01-autumn-journey/production/render-night-sticker-v2.py)在变换前预乘alpha，避免透明边插值产生黑边；不把纸贴周围的玻璃一起冻结。透明原图、按alpha包围盒裁切与等比缩放后的输入都保留。蓝眼、发色、服装、两叶鲸尾及场景暗部曝光另行核对，不能以技术合成成功作为内容通过。

## 动作方向与尾鳍拓扑要从首帧修正

S16原图脚尖面对镜头，模型生成倒退上楼；固定裁切只能排除错误印花，不能修正步态。新首帧改成后方看鞋跟、脚尖朝上坡，再明确要求向前踩高一级、足底落稳、重心上升并离开镜头。检查整个序列的承重脚和移动方向，不能用倒放或改名解释错误动作。

S10、S23、S34、S37原尾柄穿过分叉后继续延伸，形成第三根竖刺。先用imagegen修正四张首帧为一个相连尾柄、在末端只有左右两叶，再重生成；不能只在负面提示里写“不要第三根”同时继续输入错误原图。侧面尾巴与周边图案也要检查，不能把衣褶或真实连接的尾柄一律擦掉。

## 低纹理布袋的自动跟踪失败时

S37新源片有明显的相机靠近和布袋形变。直接首帧LK在第76帧失去可靠拟合；改成每24帧重新取点虽然跟完120帧，末端袋边仍漂移约数十像素。因此“成功跟完”不能作为位置正确的证明，重设种子或增加尺度容差不能代替实际边缘检查。未采用的分段跟踪实验代码保存在本期`production/experiments/`。

最终候选按实际袋边／拉链观察11个平面关键帧，插值各帧四边形，将完整原始印花投射到袋面，同时用空白布料区域匹配场景曝光。它是带人工观察锚点的平面近似，不是精确的非刚性布料重建；需要完整查看印花相对拉链、缝线和手的位置。

前两组羽化范围留下原图呆毛／鞋的浅重影，扩大覆盖的第三组又把原图草地带到袋口，均未采用。第四组明确限制原图材质轮廓、修正拉链锚点，并保护原有手的遮挡：不投射参考图的皮肤像素，保留当前源片中实际相连的握袋手。皮肤阈值只在本镜受限握袋区域内使用，不能推广成通用人物分割或用来隐藏新增人员。

当前入口为[投射几何](../video-maker/tools/project_keyframed_print.py)、[手部保护及材质边界版本](../video-maker/tools/project_keyframed_print_occlusion_v2.py)、[实际参数](../series/deepseek/autumn-journey/episodes/01-autumn-journey/postproduction-plan-v2-keyframed-print04-768p.json)。前三组代码、计划和成品保留；当前采用值与逐帧检查绑定在[源片复核记录](../series/deepseek/autumn-journey/episodes/01-autumn-journey/production/source-review-v2-keyframed04.json)。

## 验证与复用

- [针对性测试](../video-maker/tools/test_stabilize_carrier_plane.py)验证：改变图案内部动画不影响载体变换，缺失载体特征会拒绝，越界蒙版会拒绝。测试只证明程序行为，不证明实际影片美观。
- [关键帧几何测试](../video-maker/tools/test_project_keyframed_print.py)验证精确锚点与中间平面、禁止越过已观察帧外推、拒绝反射／交叉四边形；不替代实际袋边和手部遮挡检查。
- [源片检查器](../series/deepseek/autumn-journey/episodes/01-autumn-journey/production/prepare-source-proof-v2.py)完整解码原生源片，保存所有帧的有序整景图册、指定局部和原生帧；输出明确不自动宣告实际看过或审核通过。
- [独立装配器](../series/deepseek/autumn-journey/episodes/01-autumn-journey/production/assemble-reviewed-film-v2.py)要求八段替换源片逐一有实际通过决定且指纹相符，40段未改源片只转移原有决定；核对全部48镜起点和时长，保留205秒／6150帧与原配乐。

已提交模型请求、审核和后期计划的文件必须保持原始字节。此次为已经绑定的少量CRLF文件设置精确保留规则，并检查Git暂存区与实际使用文件一致，避免换机器检出时换行转换使审核失效。后续新文档应在计算指纹前使用LF；不能为排版直接改写已经提交的计划。

原始候选、失败处理、完整请求、代码版本和中间媒体保留。新图片及检查图入本期Git；大型源片与影片放仓库外，Release提供可播放成片。人格与披露审核绑定最终实际计划和素材，技术检查、助手审图、人工连续播放和用户验收分别记录。
