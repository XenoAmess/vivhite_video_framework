# video-maker：自动化数学科普视频制作器

Java 包前缀：`com.xenoamess.vivhite_video_framework.maker`。

本模块负责将数学选题制作成完整的科普视频，并利用分析器提炼的风格和改进建议优化成片。目前仅建立 Maven 模块与包结构，以下为后续实现的职责约定。

## 输入与输出

- 输入：数学主题、目标受众、目标时长、语言、画面规格，以及可选的视频分析报告或风格配置。
- 输出：成片，以及可追溯的文案、分镜、素材引用、字幕、渲染配置和制作记录。

## 制作流程

1. 明确主题、受众、学习目标和需要解释的数学概念，核验公式、推导与示例。
2. 规划叙事结构，生成文案和逐镜头分镜，为每段讲解分配时长。
3. 根据风格配置生成或选择图形、公式、动画、配音、字幕和音效。
4. 按时间轴合成、渲染视频，检查数学表达、音画同步、字幕、时长和导出规格。
5. 根据质量检查及分析器反馈调整制作参数，记录可复现的制作过程。

## 与分析器协作

- 将分析器报告中的配色、版式、镜头节奏、公式呈现、叙事策略等转为制作参数。
- 参考分镜和表达方法，结合新的数学主题重新创作文案与画面。
- 消费有版本标识的结构化报告，不直接依赖分析器的内部实现，也不调用其 GPT 接口。
- 对缺失证据、低置信度结论和不适用于当前选题的建议保留可配置的处理方式。

## 构建

在仓库根目录执行：

```powershell
.\mvnw.cmd -pl video-maker -am verify
```

macOS / Linux 使用 `./mvnw -pl video-maker -am verify`。当前尚无应用入口或视频渲染功能。
