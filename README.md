# vivhite_video_framework

以 Java 为主要开发语言的视频框架项目，目前处于初始化阶段。

## 开发约定

- 主要语言：Java。
- 文件编码：UTF-8；Java 代码使用 4 个空格缩进。
- JDK 版本、构建工具和模块结构将在开始实现时确定，并在本文档中补充运行与验证命令。
- 自动化协作规范见 [AGENTS.md](AGENTS.md)。完成有文件变更的任务后，默认检查、Git 提交并推送。
