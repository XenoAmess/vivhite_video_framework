## 1. 本轮重新检查了什么

对照对象为真理院七叶的《【数学】怎么动动尺子就能算 BMI 和解方程？从计算尺到列线图》，视频指纹沿用既有报告；被评估对象是 `3abf5c9` 基线上的 v1 `director-template.json`，文件 SHA-256 为 `082a26e5c9857e4c746b0a25c87b8b9c3b7c75e0e818ad352be434afd4a31e52`。

本轮重新阅读目标片全部 441 段 ASR，重新查看贯穿全片的 188 张选帧、16 张联系表；再从原视频按 1 秒间隔提取并查看四个关键区间，共 214 张取帧、14 张联系表。新增取帧与原选帧存在重叠，不将两者相加当作互异帧数。

| 额外检查的原片区间 | 重新检查的问题 |
| --- | --- |
| 00:37–01:54 | 函数图怎样变成函数尺，角色、标注、读数和数学结论如何配合 |
| 06:19–06:51 | 上一种工具的自由度不足，怎样引出两张图的平移 |
| 11:29–12:25 | 同一三轴装置怎样连续变成加法、带系数、减法和加常数 |

## 2. 目标片最有辨识度的结构

目标片围绕一组持续改造的计算工具展开：

```text
先看到 BMI 图能用
  → 函数图把数值搬到刻度上
  → 两把尺能读取函数和逆函数
  → 一个输入不够：让尺子滑动，容纳第二个输入
  → 已经会加法：换成对数刻度就能乘除
  → 一个自由度不够：两张图在平面上移动
  → 不想移动透明图：把方程改成三点共线
  → 从最简单的三轴装置开始，连续调整尺度、方向和位置
  → 组装出体重/身高²，再整理成片头 BMI 图
```

这是对全文和画面组织的归纳，不是作者明确声明的固定模板。它的关键在于，观众知道眼前对象**刚获得了什么能力、还缺什么能力、下一步为什么要改它**。不是每段都要解释完整的代数推导，但主图中发生的事能支持口播结论。

v1 的实际顺序是“谜题→规则→DFS/BFS→A*→人工解法→2×2→逆序→对换证明→不变量→判定→路线”。知识点彼此有关，但大部分切换发生在讲述目录层面。观众需要先听多种方法，再等主线工具出现。

目标片也会重置画面，例如约 11:03 先放下圆和双曲线，回到最简单的三轴。需要继承的是明确的需求与已有操作能力，不要求每一章都由上一幅图连续变形而来。拼图的离散合法动作、排列证明和几何表示也应区分，不能为了视觉连贯而编造数学等价。

## 3. 四段可以直接指导改稿的演示

### 3.1 00:48.840–01:53.880：观众看见工具被制造出来

| 原片动作 | 得到的新信息 | 对拼图新稿的启发 |
| --- | --- | --- |
| 横轴刻度沿曲线投影到一把空尺 | 标签仍是原数，位置由平方决定 | 同一个数字可以保持身份，同时改用另一种表示 |
| 函数图淡出，留下两把刻度尺 | 原来图像中的关系被装进尺子 | 棋盘展开时，要留下“谁接到哪个排序位置”的关系 |
| 两尺取下、转向、并排，指示线读数 | 平方操作可以直接使用 | 逆序应被“看见并数出”，不只是由旁白给出定义 |
| 反向读，再加入游标 | 同一装置获得逆运算和可操作形式 | 继续改变同一装置，让观众看到操作的另一种结果 |

图形运动带来了可读的数学关系。v1 的“保持 tile ID”是必要工程安排，却不能自动保证这一点：同一个数字还在画面上，不代表它已经承担推理。

### 3.2 06:19.820–06:50.240：下一章的对象有明确来历

原片先回顾滑动尺为什么能容纳第二个输入，再问更多自由度会怎样；随后两张图叠起来，演示上下左右移动，才给出二次方程计算图。

这段改变了一个具体条件：可动维度增加。旧稿从 BFS 讲到 A*，再讲人类解法，虽然顺序合理，却没有相同强度的“当前装置改变一个条件，下一件东西就出现”的联系。

拼图新稿可以让“回路里的顺序不变”自然产生“给顺序记一个数”的需求；再由“这个数每步会翻转”产生“空格还提供了另一个翻转量”的需求。每个定义解决一个刚刚在画面里遇到的问题。

### 3.3 11:29.500–12:24.380：不是一张图停住讲完一段

同一三轴图在约 55 秒内完成四轮明确改造：

| 原片区间 | 操作与可见结果 |
| --- | --- |
| 11:29.500–11:44.860 | 压缩中间刻度距离，同一物理高度的读数翻倍，平均值变成和 |
| 11:45.260–12:04.300 | 拉伸输入轴，输入相同数字时贡献不同物理高度，产生系数 |
| 12:04.780–12:12.100 | 翻转右轴，系数改变符号 |
| 12:12.580–12:24.380 | 平移结果尺，所有读数增加常数 |

这里的节拍是“提出局部需求→改一个对象→读到新结果→关系式更新”。区间根据 ASR 和图像共同定位，不是自动检测的剪辑点；实际动作在句间重叠。

因此，不能用“目标片每几秒切镜”代替分析。它可以在同一个长场景中保持构图，同时持续产生新状态。v1 大量 30–40 秒场景的问题也不在长度本身，而在内部动作和论证状态没有充分展开。

### 3.4 12:25.000–14:09.320：结尾回收整条构造链

三轴平均数装置重新换成对数刻度、调整输出尺度，得到乘积；改变输入输出或翻转一轴，得到除法；再拉伸一轴，得到除以平方；代入体重和身高的含义，最后进行几何重排，变成片头图。

开场的图不是在结尾重新放一次，而是被前文积累的操作**一步步构造出来**。新稿需要把展开排列、交叉计数、空格颜色和组合标记装回原棋盘；随后操作一次，让这套东西当场预测并验证结果。单独把同一棋盘再展示一次，闭环力度不足。

## 5. 三处此前被误读的风格

### 5.1 角色不是只在章节转换时露面

00:41–00:49 的小角色配合从横轴找到曲线；01:20、01:31–01:34 在平方/开方读数旁反应；04:50–05:05 配合借位与补偿；07:35 对简单读根作轻松反应；10:50 和 14:00 随变换转动。大主持在解释能力变化、引入新对象和总结时承担过桥，小角色则进入演示内部。

v1 把它限制为疑问或总结处约 2–3 秒，主动删掉了目标片的一部分表现力。修订应安排原创角色去指示、操作和反应。角色出现次数本身不能作为风格分数；动作和数学事件之间的关系才需要检查。

### 5.2 “简洁”不等于只保留低密度图形

08:15–08:30 的复根解释、10:10–10:20 的双曲线推导、10:50 的变换说明，都允许次层公式存在；口播把注意力留在当前装置如何工作。数学内容较深，但阅读层次清楚。

旧稿把很多限制、对照和方法说明依次读出来，再叠加普遍停顿，形成讲义感。新稿需明确三层：必须听懂的关键因果、能从主图读到的操作结果、可停下来深读的推导和注释。关键证明与条件仍要准确；不能为轻快而把必要条件冒充充分条件。

### 5.3 语言是“我改一下，你看发生了什么”

从全文可见，定位、搬刻度、对齐、换尺度、翻转、平移、读出结果等具体动词持续推动画面。轻微反问、嫌麻烦和惊喜来自当前操作。例如 00:28–00:32 的复杂图预告、07:33–07:42 的读根反应、08:48 后对透明片的过桥，都有局部作用。

v1 反复使用“先分清两件事”“不能直接下结论”“配套文档已验证”等说明性句子。它们可以帮助制作和审稿，却不都适合成为观众的讲述主线。新稿应先写眼睛和手正在做的事，再写解释，以及紧接着值得试的新变化。

## 6. 节奏差异的可复算证据

统一统计 Unicode 字母及十进制数字，包含中文字符，去掉标点与空白；分母保留区间内全部时间，含停顿。目标片以 `s00440` 结束的 900.240 秒为正文终点，排除未确认的片尾 `s00441`；旧稿以片尾镜头 20 的起点 715 秒为正文终点。

| 相同统计口径 | 目标片 ASR 正文 | v1 正文计划 |
| --- | ---: | ---: |
| 时间 | 900.240 秒 | 715 秒 |
| 字母/数字字符 | 4718 | 2310 |
| 每秒文本字符 | 5.241 | 3.231 |

v1 约为目标片正文文本密度的 **61.6%**。目标片七个不同讲解区间的同口径结果约为 5.10–5.37 字符/秒，不只开头一段较密。

这不是实际音频语速比较：目标来自含识别误差的 ASR，旧稿尚无配音，数字和公式的读法也会影响时长。没有把 ASR 段长度与导演场景长度当成同一种单位，也不据此推算切镜率。旧稿场景时长中位数是 40 秒，仅说明其规划方式。

下一稿应从动作和配音重新分配时间：需要看清的移动留时间；已明白的关系通过变式继续推进；检查性口播压到次层；每次停顿都有观察任务。不能单纯把配音统一加速，也不能把一堆静止解释删掉之后仍硬撑到 12:20。20 镜和 12:20 都是 v1 的预算，不是从参考片验证得到的风格条件。

## 7. 系统层面的失误

1. **跨段构造关系未进入风格描述。** 30 秒窗口便于覆盖，但此前跨窗归纳主要产出了外观和一般叙事规则，没有保存“哪个装置继承哪个装置、为什么换表示”。
2. **风格规则缺少正反对照。** “持续对象”“先演示后解释”几乎适用于所有数学视频；没有对照实例说明怎样的动画只是重复旁白、怎样的动画承担了推理。
3. **生成任务优先知识点全覆盖。** 旧稿顺着源片的搜索和解法目录保留内容，风格迁移主要发生在之后的包装层。
4. **节奏先验没有从目标片校准。** `DirectorPlanner` 的通用提示为 3–5 字符/秒；本例实际旧稿正文仅约 3.23，参考片同口径约 5.24。应先建节拍和信息层次，再用密度诊断，不把固定范围当作所有视频的目标。
5. **结构通过被误当成可制作的风格通过。** 当前校验检查指纹、引用、覆盖、连续计时和旁白过载；`styleRuleIds` 存在，不代表动作落实了相应表达机制。`director-validation.json` 的 `passed` 只表示这些结构检查通过。

本次用单独的 v2 风格重写依据补齐上述缺口。原分析报告和 v1 导演稿保留作对照，本轮未把它们重新绑定到新分析后伪装为已完成的 v2。

## 8. 建议的新主线与内容去向

新主线建议为：**把滑块的操作规则，逐步做成一个可读的图形判别工具。** 这是一项新的创作方案，需要验证表达效果；不是参考片原本使用过的拼图方案。

| 段落 | 继承的对象 | 当前操作与新能力 | 内容覆盖 |
| --- | --- | --- | --- |
| 开场 | 原局面、目标与判别器预览 | 用一次实际判断给结果，再问装置如何工作 | K01、K09 的问题与用途 |
| 小棋盘与回路 | 合法滑动、可活动区域 | 局部绕行、行尾配对、缩小区域，看到 2×2 的循环次序 | K03、K04 |
| 从顺序到交叉 | 棋盘中的同一组数字 | 展开并连接升序参照位置，交叉对数成为逆序 | K05；计数复杂度可置次层 |
| 对换到空格 | 刚构造的交叉表示 | 看一次交换如何翻转奇偶，再发现空格颜色也翻转 | K06、K07 的证明与动机 |
| 组装判别器 | 交叉奇偶、空格颜色 | 合成标记、比较目标，展示两类及规则条件 | K07、K08；一般化与有限枚举分开 |
| 判断之后找路线 | 已知同类的两个状态 | 展开状态图、用 BFS 找路线；DFS/A* 作不同搜索策略的简短比较，播放已验证路径 | K02、K09 |
| 回收 | 前文造出的全部主要对象 | 装回开场棋盘，做一次反例或变式，只总结一次 | 学习目标与来源说明 |

所有 K01–K09 的核心含义仍需覆盖，但可以重排、合并、分配到口播、图形和可选注释。篇幅与镜头数在实际配音/动作预算后确定，不预先将此候选顺序锁成又一套等长段落。

## 9. 90 秒方向样稿

以下是可直接阅读的方向示例，完整动作与数学备注见 [JSON](../../../../video-maker/examples/puzzle-restyle/opening-direction-v2.json)。它先使用判别器，再回到最小棋盘构造原理；后续正文必须补齐交叉计数、空格修正与可达性依据。

**00:00–00:10**

假设我们想把这块滑块拼图，拼成右边这个样子。通常要一块一块地试，不过今天先用一个更省事的办法。

**00:10–00:23**

把数字排成一行，数一数有多少对连线相交，再看空格落在什么颜色的格子上，就能算出一个零或一的标记。只要它和目标不同，这局就不用再试了。

**00:23–00:34**

比如这一局，算出来是一，目标是零，靠正常滑动就到不了。旁边这一局则和目标一样，都是零，它确实能还原，等会儿我们把路线走给你看。

**00:34–00:43**

奇怪的是，这个标记根本不记录你走了几步，却知道你能去哪一类局面。它是怎么做到的呢？我们先从最小的拼图开始。

**00:43–00:55**

这里有三个数字和一个空格。让一块滑进空格，下一块再跟上，走过一圈后，空格回来了，三个数字的位置却轮换了一次。

**00:55–01:09**

把四个位置画成一个环，就能看清这个过程。滑动可以改变它们的位置，却改变不了一、二、三沿着环排列的先后顺序。再怎么绕，也不会把顺时针的一二三变成一三二。

**01:09–01:20**

四个位置一共有二十四种排列，而每个圈子各有十二种。可是，总不能每次都把全部局面画出来吧？这个顺序，能不能用一个数来记住？

**01:20–01:30**

换成大棋盘，光看圆环就不够了。我们把棋盘摊成一行，再让每个数字接到排好序的位置，看看这些线会怎样交叉。

图形上，开场三步操作为后文工具作预告；小棋盘到环再到排列用同一对象过桥；角色把注意力指向当前操作。浅纸底和章卡继续使用，但不再承担主要的“像不像”判断。

## 10. 下一稿怎样验收

先保留原有数学与结构检查，再逐段人工/模型对照以下问题，并给出目标片时码、新稿动作及观察到的差异：

- 开场能否实际看见输入、操作和输出？
- 每次换表示，是否解决了眼前装置刚暴露的局限？
- 至少一个关键结论是否由可观察变化直接产生，而非全靠旁白？
- 长场景中是否有连续的新状态与新关系，停留时观众在做什么？
- 口播、主图与可选推导是否分工，指示词能否找到具体对象？
- 原创角色是否在帮助指示、操作或反应，轻松语气是否来自当前事件？
- 结尾是否把前文能力组装回开场，并只做一次收束？
- 数学前提、证明、同标记充分性和每步合法动作是否仍然正确？

不把“纸色+紫章卡+9 个风格规则引用齐全”作为通过标准，也不给尚无成片的导演稿捏造整体相似度百分比。后续音频和渲染执行需分别评估。
