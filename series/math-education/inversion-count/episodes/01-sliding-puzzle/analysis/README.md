## 数学校正与独立验证

从左到右、从上到下展开，包含空格 `0`。逆序数 `τ` 为满足 `i<j` 且 `a[i]>a[j]` 的数对数量。行、列索引 `r,c` 都从 0 起。

1. 相邻排列交换翻转逆序数奇偶；端点距离为 d 的对换可拆成 2d−1 次相邻交换，所以任意一次对换也翻转奇偶。
2. 一次合法滑动就是交换 `0` 与一个共边滑块；它也让空格的 `r+c` 奇偶翻转。
3. 因而 `I=(τ+r+c) mod2` 不变。整数 `τ+r+c` 本身可以变化。
4. 起点和目标的 I 不同，一定不可达。I 相同是否足够，需要另外证明连通性；本例对全部 2×3 排列精确枚举验证，而不是把必要条件直接说成充分条件。

| 局面 | 包含 0 的逆序数 | 空格坐标 | τ+r+c | I |
| --- | ---: | --- | ---: | ---: |
| 原例起点 `[2,3,1;4,5,0]` | 7 | (1,2) | 10 | 0 |
| 目标 `[1,2,3;4,5,0]` | 5 | (1,2) | 8 | 0 |
| 无解反例 `[2,1,3;4,5,0]` | 6 | (1,2) | 9 | 1 |

原片使用一基坐标，起点/目标的加和分别为 12/10；新稿零基为 10/8，奇偶结论相同。原片先有口头误加，后已更正，不能凭 ASR 片段指责其最终结果错误。

BFS 最短路径共 14 步（每个字符代表一格，保留前导 0）：

```text
231450 → 230451 → 203451 → 023451 → 423051
→ 423501 → 423510 → 420513 → 402513 → 412503
→ 412053 → 012453 → 102453 → 120453 → 123450
```

Java 检查了每一步的共边交换、全程不变量及起终点；对 2×2 的 24 排列、2×3 的 720 排列逐一比较可达性与奇偶签名，得到 12+12、360+360。这些有限枚举不替代一般尺寸的证明。至少两行两列、单空格、所有块互异、仅共边移动的完整矩形有相应一般结果；一维棋盘、障碍或其他规则需另行研究。

数学延伸阅读：[Princeton COS226 作业说明](https://www.cs.princeton.edu/courses/archive/fall18/cos226/assignments/8puzzle/specification.php)、[课程讲义](https://www.cs.princeton.edu/courses/archive/spring18/cos226/meetings/cm8-8puzzle.pdf)。其中常见定义省略空格，使用该公式前必须换算定义，不能与本稿的含 0 逆序数混用。

| 参考片观察 | 可定位的证据 | 新稿的执行方式 |
| --- | --- | --- |
| 先给可操作结果再解释 | 00:00–00:19 连线读 BMI | 先给可还原棋盘和人为对换后的无解棋盘 |

| 紫色编号章卡、标签与结论带 | 00:45、02:30、06:35、11:05 | 五章推进；一章末只留一句可复述结论 |
| 主图、公式、底部单行字幕分层 | 01:30、07:30、13:50 | 主图不被字幕遮挡，公式贴近相关对象，推导逐步加信息 |

| 回到开场问题 | 13:30–14:09 的 BMI 构造 | 回收开场原局面，播放可复算的 14 步路径 |
| 片尾列资料与适用条件 | 15:00–15:36 | 内容来源与风格来源分别署名，列定义、验证代码和范围 |
