## 导演总则与制作边界

一条构造主线贯穿全片：**在棋盘上造一个能搬去任意位置的三轮换工具，再把相接的工具接成能处理所有偶置换的机器，最后接回第一期的判别器。** 不以播放一套群论课件代替这个过程。每次出现符号，先让当前牌或工具遇到一个具体的新需求。

主要舞台一直是开场的 `3×4` 棋盘。右侧保留目标缩略图；底部逐步装配“归根路径 → 方格三轮换 → 三角接力 → 全部偶置换”工具栏。需要一般论证时，镜头拉远，将同一棋盘的格线继续延长，并保留变量边界标注，不通过列举大棋盘来充当一般证明。

主视觉沿用目标参考片复分析得到的机制：纸色底、细线、紫色操作和青色结果；同一对象持续改造；句子中的“这里”“这个”都有高亮对象；主图承担推理，公式为可追踪的第二层。主角指示或触发当前数学动作。全片只安排一次轻微指错格子的可恢复失误，不反复插入角色小剧场。

## 全量分镜与旁白

### 01｜00:00–00:30｜先让判别器工作，再问它少了什么

**旁白：**

这两盘拼图，都想拼成右边的样子。把空格也排进去，数一下逆序的奇偶，再加上空格的行号和列号。左边和目标一样，都是零；右边是一。这一盘到不了，这一盘呢？今天，我要给这个绿色结果补上一套动作。只要棋盘是完整的矩形，而且至少两行两列，标记相同，就一定能拼到。不是只试这张棋盘。我们把棋盘拉长、加宽以后，理由也得继续管用。

**动作：** 以验证数据生成目标、可达局面、再交换位置 8 与 9 的不可达局面。两次实际计算使结果分别亮绿和红；不可达局面缩为右下角书签。白绮的指示杖把绿色输出向右拖，露出尚未安装的“合法路线”插槽。开场不先讲定义清单。

**屏幕：** `I = inv(含0) + r₀ + c₀ mod 2`；目标 `I=0`，可达例 `I=0`，不可达例 `I=1`。边框固定条件条：`完整矩形；m,n≥2；一空格；牌互异`。

### 02｜00:30–01:01｜把结论改写成眼前要完成的任务

**旁白：**

上一期这两个小读数，每走一步都会一起翻转，所以合起来不变。它能拦住红色的局面，却还没有给绿色局面铺路。说不定标记相同的局面里，还藏着别的障碍呢？要排除这种可能，我们得造出足够多的合法动作。先把空格送到左上角，别急着排好数字。我想在空格每次都回来的条件下，只让三张牌轮流换位。这个动作只要能到处安装，整张棋盘就有办法接起来。

**动作：** 原判别器只画出“不可达”的挡板；白绮将“同标记？”绿色端口接到一个空白动作轨道，明确显示充分性尚未补上。保留棋盘数字，空格根位置画圆。框出一个单位方格，但暂不移动牌。

**屏幕：** 当前需求 `同标记 → 造出路线`。根位置 `o=(0,0)`；新工具目标 `空格回来；只动三个位置`。

### 03｜01:01–01:37｜把一格一步，接回同一个不变量

**旁白：**

先确认这个读数没有换算法。这里的零就是空格，展开时也保留它。零和旁边一张牌交换，整个排列的奇偶会翻转；空格跨过一条网格边，黑白颜色也会翻转。两次翻转相加，结果还是原来的零或一。为什么隔着几格交换也会翻转排列奇偶？把一次远处交换拆开：先把一张牌一路挪过去，再把中间的牌挪回来，总共是距离的两倍减一步，是奇数次相邻交换。因此，整张棋盘怎么滑，这个合成读数都留着。

**动作：** 主棋盘走一合法步，含零连线和空格颜色同步翻转。随后仅在“排列分析层”上演示两位置相距 `d` 的交换展开，明确该层相邻交换是计算排列符号，不是棋盘合法滑动；完成后收回原棋盘。

**屏幕：** `对换 = 2d−1 次相邻对换 → 奇偶翻转`；`Δinv≡1, Δ(r₀+c₀)≡1 → ΔI≡0 (mod 2)`。分析层始终标 `计算排列奇偶，不是滑块动作`。

### 04｜01:37–02:13｜统一空格位置，减少一个自由度

**旁白：**

现在把起点和目标的空格，都送到这个左上角。只要棋盘连着，沿行沿列走过去就行。走过的路会打乱一些牌，先记住这条路，待会儿可以倒着走回来。两个局面原来同标记，走完仍然同标记；空格现在又站在同一个位置，所以剩下数字排列的奇偶也相同。我们的任务就缩成了：空格一直回到这里时，能不能把数字之间任何一个偶置换做出来？把这件事做好，两边的归根路径再接回来，就完成了。

**动作：** 同一棋盘复制为上下两个小窗 `S,T`，各用独立真实路径将空格送根，路径保存为两张可倒放磁带 `P_S,P_T`。两灯重新同步，右侧出现尚空白的中段连接器。此时不宣称中段已经存在。

**屏幕：** `S → S′    T → T′`；两根空格固定，`I(S′)=I(T′) → 排列差为偶`；待造 `S′ → T′`。

### 05｜02:13–02:47｜在最小方格里造出第一个工具

**旁白：**

先只看这四个格子。空格在左上角，沿左边下去，再向右、向上、向左，绕一圈回来。盯着另外三个位置：右上角原来的牌去了右下角，右下角的去了左下角，左下角的去了右上角。三张牌接力了一次，其他格子没有动。把这三个位置叫作甲、乙、丙，这就是甲到乙、乙到丙、丙到甲的三轮换。倒着绕一圈，接力方向也就反过来。正反两个方向，我们都拿到了。

**动作：** 放大左上 `2×2`，空格依 `h→c→b→a→h` 走四步；每张牌保留起始颜色和细尾线。先看实际移动结果，再在三个非空格位置间接上三角箭头。工具以小图标停靠底栏，不另切群论标题页。

**屏幕：** `h a / c b`；路径 `h→c→b→a→h`；位置作用 `(a b c)`；倒放为 `(a c b)`。每步仍只交换空格与相邻牌。

### 06｜02:47–03:18｜工具还够不着远处

**旁白：**

这个小三角现在只能在角上转，离右下角还远。把它搬过去，能不能做完以后，让路上的牌也回到原位？先选远处的这个方格，左上角叫作入口。我的法杖指这里——咳，刚才偏了一格，是这个左上角。我们让空格走到入口，再绕这四条边，最后沿原路回来。关键不在路有多长，而在去程有没有碰到那三个要转的位置。碰不到，返回时就能把路上的变化完整撤掉。

**动作：** 主棋盘恢复全景，白绮指示杖短暂落到目标方格右上角，立即改指左上入口，0.8 秒内恢复自信姿势。去程先只画虚线，出现“避开三角三个位置”的限制。此后全片不再安排类似失误。

**屏幕：** 入口 `h=(i,j)`，三角三个角 `a,b,c`；工具升级需求 `归根路径不经过 a,b,c`。

### 07｜03:18–03:53｜给任意方格安装同一种接线

**旁白：**

这条路可以统一画：从左上角沿最上面一行走到入口所在的列，再沿这一列往下走，停在入口。入口右边的甲和右下的乙，都在更右边的一列，碰不到；入口下面的丙在同一列，但我们到入口就停下，也碰不到。这个画法只看行号和列号，不看棋盘究竟多大。入口就在最上行时，下行这一段省掉；就在最左列时，横走这一段省掉；就在根上时，去程全省掉。边上的方格也能装。

**动作：** 先在 `3×4` 选择 `(i,j)=(1,2)`，再连续拉长格线为变量框；主路径始终保持顶部横段和第 `j` 列竖段。将三点分别投影到“列更大”“行更大”的边界，图形直接说明避开原因。三个边界情况在同一图上收缩路径，不换成三张静态结论卡。

**屏幕：** `P: (0,0)→(0,j)→(i,j)`；`a=(i,j+1), b=(i+1,j+1), c=(i+1,j)`；`0≤i<m−1, 0≤j<n−1`。

### 08｜03:53–04:33｜把去程、绕圈和返程逐项抵消

**旁白：**

现在真的走一次。空格沿紫线过去，路上的牌依次让位。到入口后绕一圈，只有青色这三个位置的牌在接力；紫线路上的内容，跟绕圈以前完全一样。于是原路返回时，每一步都恰好撤销去程的对应一步。不是把路上的牌忽略了，是它们真的一张一张回来了。最后空格回到根，只有那三个位置轮换。这就是能装在任意单位方格上的小工具。它的作用不取决于这三张牌写着什么数字，只取决于它们站在哪里。

**动作：** 展示三条同步时间带：去程扰动、方格回路、返程复原。每次返程交换都与对应去程交换用弧线配对销去；走完逐格比较起始快照，只有三点有差异。绝不直接把路上的牌淡出或瞬移复原。

**屏幕：** 操作队列 `走 P → 方格绕圈 → 倒放 P`；结果 `仅 (a b c)，空格回 o`；补注 `P 避开 a,b,c，所以返程确实撤销去程`。

### 09｜04:33–05:10｜把工具铺开，先检查有没有漏掉位置

**旁白：**

把每个单位方格都装上一个三角。现在看它们能接触到哪些位置。最上面一行，除了根以外，每个位置都是某个方格的右上角；最左边一列，除了根以外，都是某个方格的左下角；剩下同时不在顶行和左列的位置，都是左上邻居那个方格的右下角。三种情况把根以外的每个位置都接到了。根恰好没有接进去，因为空格要留在那里。到这里，我们还只知道每个位置有工具能碰到，接下来要看这些工具能不能互相借力。

**动作：** 同一棋盘上依次亮起顶行非根、左列非根、内区，分别追溯到一个具体单位方格；随后拉伸到一般 `m×n`，三种高亮区域仍覆盖所有非根位置。根始终灰色，防止误称能任意移动空格。

**屏幕：** `r=0,c≥1 → T(0,c−1)`；`r≥1,c=0 → T(r−1,0)`；`r≥1,c≥1 → T(r−1,c−1)`；`⋃T(i,j)=全部非根位置`。

### 10｜05:10–05:46｜把每个方格连成可接力的网

**旁白：**

横着相邻的两个方格，共有这个下边的点；竖着相邻的两个，也共有这个靠右的点。沿着一排方格走，再走到下一排，所有方格都能这样接起来。这不是要求三角形必须共一整条边，共一个点也可以。只有两行时，它们排成一条横链；只有两列时排成一条竖链；最小的二乘二，根本只有一个三角，没有其他地方要接。任意有限矩形里，这张网都没有断开的另一块。现在的问题，变成了一个更小的装配问题。

**动作：** 高亮横邻、竖邻的实际共同点；支持图抽象为方格节点，显示逐行遍历的连通路线。再把 `m−1` 或 `n−1` 收缩为 1，最后两个都为 1。完整矩形边框全程保留。

**屏幕：** 单位方格节点网 `(m−1)×(n−1)` 连通；工具支持相交 `T(i,j)∩T(i,j+1)≠∅` 与 `T(i,j)∩T(i+1,j)≠∅`。

### 11｜05:46–06:24｜只转三张，为什么够用

**旁白：**

我们造出来的是三张接力，却要处理所有同奇偶的排列。先在这条展开的牌列上，把任务说清楚：任何排列都能靠交换两张牌还原。更具体一点，反复找一对相邻、顺序颠倒的牌，把它们换过来。它们和外面所有牌的前后关系都不变，只有这一对逆序被消掉，所以每换一次，逆序数恰好少一。最后逆序数归零，排列排好。如果起初逆序数是偶数，就用了偶数次交换。把这串交换两两捆起来，看看一捆能不能改造成三张接力。

**动作：** 从主棋盘抽出同一组带位置标记的标签到排列分析带，使用相邻逆序冒泡；计数每次减 1。交换磁带按顺序两两装盒。分析带明确不是合法滑块路径，随后每盒再由真正方格工具实现。

**屏幕：** `一次相邻逆序交换：inv→inv−1`；`偶置换→偶数个对换→两两分组`。区域标签 `排列分解层`。

### 12｜06:24–07:01｜一捆两个交换，拆成三角动作

**旁白：**

同一对牌交换两遍，直接抵消。两个交换共有一张牌，就成了三张牌的轮换。最麻烦的是两对完全分开：甲乙交换，丙丁交换。先转甲丙丁，再转甲丙乙，追一下每张牌：甲最后到乙，乙回甲，丙到丁，丁回丙。两个三轮换就把两对交换都做完了。反过来，一个三轮换本身也能拆成两个交换，所以它始终是偶的。这样，我们拿到的是准确的一整类动作：三轮换能拼出全部偶置换，而且只会拼出偶置换。

**动作：** 三个盒子依次展开；对不相交情形按实际时间先播放右侧 `(a c d)`，再播放左侧 `(a c b)`，四条牌轨迹一一对照目标双交换。每个符号与相同颜色位置连线，不让观众靠心算阅读乘积。

**屏幕：** `(a b)(b c)=(a b c)`；`(a b)(c d)=(a c b)(a c d)`；`(a b c)=(a c)(a b)`。恒定角标 `乘积从右到左；下方队列给实际先后`。

### 13｜07:01–07:39｜从一个三角开始，实际扩大可控制范围

**旁白：**

不过，刚才说的是任意三个位置都能轮换。我们手里只有方格给的这些小三角，不能偷偷把远处三点当成已经会转。先点亮第一个三角，只有三个位置时，所有偶置换就是不动、正转、反转，这些已经都会。把这三个位置圈成当前区域。接下来每次只接一个和它相碰的新三角：如果能把扩大区域里的全部偶置换也做出来，就继续往外接。棋盘和方格都有限，最后接完这张网，就能控制全部非根位置。现在来亲手做这一步扩张。

**动作：** 展开的工具网收回原棋盘，先只点亮左上三角；区域边界标 `已能做区域内全部偶置换`。准备一个新工具，三个端点分别显示“旧/新”，不直接一闪点亮整个棋盘。

**屏幕：** 归纳基础 `三点：id, (a b c), (a c b)`；待验证的扩张规则 `已控制 S + 相交新三角 → 控制更大集合`。

### 14｜07:39–08:14｜先解决两个旧点，带一个新点

**旁白：**

先接这种容易一点的：新三角里，甲和乙已经在区域内，丙是新位置。要让任意两个旧位置乌和维，也能带丙轮换，先挑一条把甲乙接到乌维的旧区域接线。执行时先倒放接线，把乌维搬到甲乙；再转甲乙丙；最后正放接线，把结果搬回乌维。这三步叫共轭：搬来，转一次，搬回。丙始终没被接线碰到。可旧区域里，我们只保证能做偶置换，所以还得确认，这条接线能选成偶的。

**动作：** 在“位置作用工具层”画出 `g⁻¹ → α → g` 的可逆轨道，与公式 `gαg⁻¹` 对应。它表示由已掌握工具生成的合法动作序列，不是把实际牌瞬移。旧区域端口 `a,b` 接至任意 `u,v`，新点 `c` 保持不动。用三根颜色固定的轨迹显示共轭结果。

**屏幕：** `α=(a b c)`；`gαg⁻¹=(g(a) g(b) c)`；实际队列 `g⁻¹ → α → g`。`g` 只作用于旧集合 `S`。

### 15｜08:14–08:51｜连线奇偶不合适，就翻转这对端口

**旁白：**

先随便把甲乙接到乌维，剩下的旧位置一一配上，总能画出一条双射。如果这条接线是偶的，直接用。如果是奇的，就在输出端再交换乌和维，让接线奇偶翻转。这样甲乙这一对，仍然送到乌维这一对，只是两端的先后反了。三轮换的方向也跟着反，我们正反方向都会，所以没有损失。现在对任意两个旧点，都能带上新点丙轮换。完全在旧区域内的三个点本来就会转，扩大后的所有三轮换就都齐了。

**动作：** 接线首先标 `g 为奇`，仅在输出端加 `(u v)` 切换为偶；无序端口框 `{u,v}` 不变，三角箭头反向。随后将所有新三角分两类：三个旧点、两个旧点加 `c`，点亮覆盖。画面可取三个旧点基例，避免误用“偶置换可有序地移动任意两点”这一在三点时不成立的断言。

**屏幕：** `g({a,b})={u,v}`；若 `g` 奇，取 `g′=(u v)g` 偶；仍有 `g′({a,b})={u,v}`。结论 `S∪{c} 上所有三轮换可用`。

### 16｜08:51–09:29｜将新增三轮换重新装进完整动作库

**旁白：**

把刚才两两捆好的交换磁带拿回来。扩大区域里的任何偶置换，先拆成三轮换；三个都是旧点的，用原来的工具；带着丙的，用刚造出的接线加三角工具。每段接线也是旧区域内的偶置换，因此有我们已经会的实际做法；每个最底层三角，最后都落实到空格去一趟、绕一圈、再回来。这里没有凭空增加远处交换。于是，两个旧点带一个新点的扩张已经完成。真正棘手的是下一种：新三角只搭上一个旧点，一次带来两个新位置。

**动作：** 将“偶置换 → 三轮换 → 共轭队列 → 旧工具 → 方格路径”层层展开，直到底部出现真实空格行走。抽出一小段完整播放后折叠为可靠工具图标。新工具改为一旧两新，显示旧边界暂时不能直接跨过去。

**屏幕：** `A(S) + (a b c), a,b∈S, c∉S → A(S∪{c})`；旁边注 `A(S)=S 上所有偶置换，不是新增黑箱定理`。

### 17｜09:29–10:05｜一旧两新，先复制一个支点

**旁白：**

现在甲是旧点，乙和丙都是新的。现成动作是甲乙丙轮换；选另一个旧点丁，再从旧区域挑一个不同的戊。旧区域至少有三个点，所以这一步总有位置可选。甲丁戊这个旧三轮换，能把甲送到丁，又完全不碰新点乙、丙。拿它给新三角重新接线，就复制出丁乙丙的轮换。看，我们有了两只几乎重叠的三角，区别只在旧支点从甲换成了丁。把它们一个反转、一个正转，试着让新点中的一个抵消掉。

**动作：** 旧点至少三个的下界在画面上实际显示。选择 `g=(a d e)`，将 `α` 共轭成 `β=(d b c)`，新点 `b,c` 不动；两工具放在同一坐标叠层，不用两张无关的符号卡。

**屏幕：** `α=(a b c)`，`g=(a d e)∈A(S)`，`β=gαg⁻¹=(d b c)`；`a,d,e∈S`，`b,c∉S`。

### 18｜10:05–10:38｜让一个新点抵消，实际追踪四条线

**旁白：**

先做丁乙丙的反向，再做甲乙丙的正向。甲不受前一步影响，后一步送到乙。乙先去丁，后一步不动丁，所以停在丁。丁先去丙，后一步从丙回到甲。最后看丙：先去乙，再从乙回丙，正好没有动。合起来，只有甲、乙、丁在接力。甲和丁都是旧点，乙是新点！刚才那个更难的接口，被我们改造成了已经解决的两个旧点带一个新点。

**动作：** 严格按 `β⁻¹ → α` 播放两轮；四条轨迹逐条合并，`c` 的闭合轨迹淡成“固定”标记，其余三点变成新三角。留 4 秒让观众对照表格，不能只显示恒等式后立即跳结论。

**屏幕：** `αβ⁻¹=(a b d)`；逐行追踪 `a→a→b`、`b→d→d`、`d→c→a`、`c→b→c`。

### 19｜10:38–11:13｜一次添两个点，分成两次扩张

**旁白：**

先用这个甲乙丁的三角，把乙接进旧区域。前面已经证明，接进去以后，扩大区域里的全部偶置换都能做。再看原来那只甲乙丙三角：甲和乙现在都变成旧点，只剩丙一个新点。再用同一条扩张规则，丙也接进来了。两个新点没有一起硬塞，而是先乙后丙，一步一步做。只要旧区域至少有三个点，接一个新三角时，无论重叠两个点，还是只重叠一个点，都可以把新增位置全部纳入控制。

**动作：** 高亮边界先跨到 `b`，停留展示可用工具扩张，再跨到 `c`；原三角由“一旧两新”实时变为“两旧一新”。将两种接口放回棋盘的支持网，仅保留操作结论，不新设抽象课堂背景。

**屏幕：** `S → S∪{b} → S∪{b,c}`；接口总表 `交2旧点：添1；交1旧点：先添1，再添1；交3旧点：无需扩张`。

### 20｜11:13–11:51｜沿相接网络，把归纳真正做完

**旁白：**

现在回到整张棋盘。第一只三角点亮三个位置，已经满足起步条件。沿着相邻的方格，把下一只三角接上。它至少和已经点亮的部分共一个点，刚才两种接口保证能继续扩大；如果三个点早就亮了，就直接跳过。所有方格都能通过相邻关系连起来，所以不会出现还有没处理的方格，却完全够不着的情况。一个方格一个方格接下去，有限棋盘只需接有限次。再加上刚才逐格检查过的覆盖，最后亮起的就是根以外的全部位置。

**动作：** 主棋盘先走一遍真实 `3×4` 支持遍历；然后将行列数拉为符号 `m,n`，边界进度动画以“一次接一个”的相同规则继续。画面分开显示“下一方格存在：连通”“最后没有漏点：覆盖”“一定终止：有限”，每一项都指回已证明对象。

**屏幕：** `起步三点 → 相交扩张 → 有限次遍历 → 全部 N−1 个非根位置`。不写“测试所有大棋盘”。

### 21｜11:51–12:24｜读出刚造好的全部能力

**旁白：**

这台机器终于装好了：只要空格先放在左上角，剩下数字之间的任何偶置换，都能拆成我们这套合法动作。反过来，空格回到左上角时，黑白颜色没有变，排列奇偶也就不能变，所以奇置换做不出来。不是机器还差一个零件，而是规则本来就禁止它。把可做的动作和做不到的动作合在一起，根上的能力恰好是全部偶置换。现在可以把开场一直空着的那一段路线接上了。

**动作：** 工具栏完整装配，绿色端口输出 `全部偶置换`，红色奇置换接口被不变量挡住。片头 `S′→T′` 空白连接器重新出现；根空格图标始终固定。

**屏幕：** `根空格合法闭合动作 = A(全部非根位置)`；`必要性排除奇置换；构造覆盖全部偶置换`。

### 22｜12:24–13:00｜把任意起点与目标接回机器

**旁白：**

把两张归根磁带拿回来。起点送空格到根，得到这里的起点撇；目标也送空格到根，得到目标撇。它们同标记，又有同一个空格，所以数字之间需要的那次重排是偶的。刚造好的机器能够把起点撇搬成目标撇。接着倒放目标那张磁带，从目标撇回到真正的目标。三段接起来，就是从原起点到原目标的一条合法路线。整个论证没有要求这两盘写着某几个特定数字，也没有要求棋盘宽度是奇数或偶数。

**动作：** 复用第 04 镜保存的同两张磁带，连接 `P_S → 偶置换机器 → reverse(P_T)`。每个接口比对完整局面快照，不只比对空格。机器中段只声称存在由证明生成的有限动作，不暗示它等于最短路线。

**屏幕：** `S → S′ → T′ → T`；第二层定义 `π：S′ 中每张牌的位置 → T′ 中同张牌的位置`，继而标 `π 固定根，且 sgn(π)=+1`。主层保留 `同根、同奇偶 → 偶重排 → 可实现`，不引入未定义的局面映射乘法。

### 23｜13:00–13:42｜将构造链装回开场，实际还原一次

**旁白：**

看回开场这盘。先处理右下的这个三角：空格去入口，倒着绕圈，再沿原路回来。这里的三张牌回到了各自的位置。再处理上面的三角，同样走过去、绕回来、原路归根。现在整盘就和目标重合了。这一例只用了两次工具，总共十六步；一般局面的分解可能长得多，我们没有在证明里保证最短。绿色标记给的是一定存在路线，刚才的装配过程解释了为什么一定存在。至于怎样把路线再压短，那是另一台机器要干的活。

**动作：** 逐步播放验证文件 `blankWalkFromOpeningToGoal` 的 16 次合法交换。按两段分别高亮 `(1,2)` 和 `(0,1)` 对应方格；可用约 0.55 秒一步，段间各停 1 秒，剩余时间用于在真实状态上跟踪三个位置与归根复原。不能在旁白尚说“去入口”时提前完成全部路径。

**屏幕：** `16 步实例，非最短性声明`；最终逐格叠印目标轮廓，判别器仍为 `I=0`。将四级工具栏收回同一个绿色输出口。

### 24｜13:42–14:16｜拿掉一行，看是哪一件工具失效

**旁白：**

现在故意把棋盘压成一行。单位方格没了，三角工具也就造不出来。比如零、二、三、一，和零、一、二、三，逆序数相差二，空格位置又一样，标记相同。可是单行里，数字永远不能越过另一张数字，非空牌的先后次序始终不变，所以这两盘仍然互相到不了。至少两行两列不是装饰条件，它保证我们真有方格和这张接力网。缺格或者改了连边，也不能把刚才的矩形证明直接套过去。

**动作：** 从原棋盘真的去掉行，工具栏的方格组件失去安装位置。用 `1×4` 两局面，保持非空牌顺序彩带不交叉；两个 `I` 读数同时为零，但彩带无法匹配。随后恢复完整矩形条件边框。

**屏幕：** `1×4: [0,2,3,1] 与 [0,1,2,3]`；`I 都为0，但非空牌顺序不同`；`m,n≥2 是本定理前提`。

### 25｜14:16–14:56｜最小与最窄的棋盘，逐项接回同一证明

**旁白：**

那二乘二会不会反而太小？不会，唯一的三角已经覆盖了全部三张数字牌，它的正反轮换，就是三张牌的全部偶置换。只有两行或两列，也只是把方格网变成一条链，覆盖和相接都还在。我们没有靠棋盘足够大来藏掉边界。小棋盘还可以把全部状态画出来核对：二乘二是两个各十二个状态的圈子，二乘三是两个各三百六十个状态的圈子。核对能发现动画或算法写错；真正让任意有限尺寸成立的，是刚才那套能一直扩张的构造。

**动作：** 同一工具网依次压为 `2×2`、`2×n`、`m×2`，每次直接展示覆盖和相接仍成立；有限状态图作为右侧小窗，分别显示完整 BFS 统计，注明“实例核对”。不将有限统计推上主证明轨道。

**屏幕：** `2×2：1 个三角即全部非根位置`；`2×n / m×2：相接链`；统计 `24=12+12`、`720=360+360`；`全尺寸依据：第 05–22 镜的一般构造`。

### 26｜14:56–15:32｜用一次完整读数，正式闭合充要条件

**旁白：**

把这盘再交换两张数字牌，空格不动，读数就变成一。无论怎样滑，它都回不到读数为零的目标。把交换撤回，同样的读数不仅没有挡住路线，而且刚才已经证明，完整矩形里不会再有第二道隐藏关卡。于是判别器上的“可能”可以改成“一定”：两个局面可以互相到达，当且仅当它们的含零逆序奇偶，加上空格零基行列和，结果相同。每个词都对应一件我们实际用过的部件，条件条也一起留在这里。

**动作：** 使用开场实际交换位置 8、9 的局面，把 `I=0` 翻为 `I=1` 后再撤回。最后才将机器标签由 `未被排除` 改为 `必可达`。主角给判别器落下“装配完成”小印，数学公式与边界保持可读至少 5 秒。

**屏幕：** `S↔T ⇔ I(S)=I(T)`；`I=inv(含0)+r₀+c₀ mod2`；完整前提条 `有限完整矩形；m,n≥2；牌互异；一空格；仅正交相邻滑动`。

### 27｜15:32–16:02｜把结论留在一张能继续使用的图上

**旁白：**

以后遇到这类矩形拼图，可以先算这个标记。不同，就不用在搜索树里继续试；相同，再去找好走的路线。这次我们用很小的方格动作，拼出了一整张大棋盘的能力。空格去远处借一次位置，原路回来；三角之间借一个支点，就能继续把新位置接进来。看起来是牌在绕圈，真正累积起来的，是可以使用的重排方式。我的这套三角接力，总算全部接通了。

**动作：** 保持最终判别器，出现两个真实功能出口：“不同→停止搜索”“相同→进入路线规划”。回放工具栏装配的缩略动图，每个只给一短操作而非再次逐条背证明。白绮在末句收杖，轻微得意，不另作长总结。

**屏幕：** `判定可达性 → 再优化路线`；底部短链 `方格回路 → 三轮换 → 相交扩张 → 全部偶置换`。

### 28｜16:02–16:37｜改变棋盘的边，留下下一期的具体问题

**旁白：**

如果把格子换成任意的点和边呢？还能走一个回路，空格也还能回来，但回路里未必恰好只有三张牌，刚才的方格网更不一定存在。比如只剩一个大圆环，牌沿环的先后顺序就会留下更多限制。下一期，我们从这些回路重新做工具，证明 Wilson 的一般图定理，也把它的条件和例外逐个找出来。今天先把这块矩形拼好。三角接力，收工。

**动作：** 已完成矩形棋盘淡为点边图，再仅保留一个长环；显示牌沿环的顺序彩带没有改变。不要画成“任何图也只剩奇偶”预告。片尾 8 秒以资料卡和两期分界呈现，人物图仍为占位；不宣称已制作新的视频形象。

**屏幕：** 下一期问题 `没有单位方格，怎样生成足够多的动作？`；资料卡：Wilson, 1974，论文标题、DOI `10.1016/0095-8956(74)90098-7`；`本期：完整矩形自含构造证明`。参考图形表达机制的原视频列为创作参考，不复制其文案、角色形象或具体动画资产。

## 制作验收点

1. 正片中必须完整保留：不变量必要性；两端归根；一般位置方格路径；返程复原理由；支持覆盖与连通；偶置换分解；交两个旧点与交一个旧点的两种扩张证明；有限归纳；接回原局面的充分性。不能将其中任何一项改成“详见附录”后仍宣称正片给了完整证明。
2. 共轭、复合和双交换的实际时间顺序必须按本稿队列播放；三轮换方向由牌的起始位置验证，不能按空格移动方向猜测。
3. 所有棋盘动作由局面状态机逐步执行，检查空格起点、边相邻、牌唯一、起止快照。抽象排列分解与实际滑块动作使用不同边框，避免把分析中的任意交换当成合法一步。
4. 任意尺寸的结论来自文字与图形中的一般构造，有限全枚举单独标注。不得用若干较大棋盘通过来替换一般证明。
5. 人物参与指示、接线、操作与结果反应；角色表演不覆盖证明关键字和牌的位置。新配音、字幕、画面道具或角色动作若引入新文案，应重新执行人格一致性和信息披露审核。
6. 第一轮样片优先检验第 07–08 镜路径复原、第 14–19 镜扩张过程和第 23 镜合法路线，再确定配音后的实际节奏。未测得这些镜头效果前，不给“风格相似度”百分比分数。
