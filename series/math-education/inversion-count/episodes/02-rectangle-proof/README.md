# 第 2 期：把判别器变成完整的证明

本期证明：对任意有限完整矩形 `m×n`，其中 `m,n≥2`，所有牌互异、只有一个空格、只允许上下左右相邻滑动时，两个局面可达，当且仅当它们的“含空格排列逆序奇偶 + 空格零基行列和”相同。

- [完整导演稿](director.md)：全量旁白、连续的工具构造、逐镜操作、屏幕公式和时间预算。
- [完整数学证明](proof.md)：用于审稿和制作的严格论证，所有引理均在本期展开，不调用 Wilson 一般定理。
- [配音与观察预算](pacing.json)：逐镜字符数、口播预算和具体观察任务；未测得实际音频。
- [验证器](verify_rectangle.py)与[实测结果](verification.json)：合法移动、三角拼接恒等式、有限小棋盘的全枚举对照。

验证器只用 Python 标准库，可在本目录运行 `py -3.12 verify_rectangle.py --output verification.json`。其中有限枚举只校验实例与制作数据；任意尺寸的结论由正文的一般证明给出。

本期为导演稿交付，尚未配音或渲染。时间是镜头预算，须在实际配音后调整；本期新增的路径、三角支持、共轭和置换分解视图尚未接入制作器，不能把此文档当作已经可渲染的生产计划。第一期不追加本期内容。
