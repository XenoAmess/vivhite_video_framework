# 真实世界美术修订：001

用户反馈部分图片“美好的不像真的”。复看全部 48 张选用场景后，主要问题是：不同地貌都出现密集花卉；雨街、车窗、山湖和市集共享过度精致的布置；金光、反光与饱和色持续出现，缺少普通天气和生活设施。

本次重做 42 镜环境，保留 S02 湖岸、S07 秋林、S25 峡谷、S27 座椅挂件、S33 海浪、S40 夜车六张已经可信的场景。漂亮的自然光和地貌仍可以出现；新版本不统一套用灰色滤镜，也不要求所有地点都老旧。

| 范围 | 调整后的场景依据 |
| --- | --- |
| 交通 | 普通列车与公交座椅、实用窗框、站台排水与安全线；窗外有农田、普通房屋、护栏、电线杆 |
| 秋林与水边 | 自然落叶、裸土、稀疏灌木、正常水色；去掉沿路持续盛开的花墙 |
| 雨街与停留 | 普通店面卷帘、路缘积水、公交雨棚、简单桌面与纸杯；去掉灯笼街式金光和精心布置的茶点 |
| 草野、高山、雪线 | 植被与海拔相符，碎石、草坡、薄雪和云层有自然差异；高山湖前不摆花园 |
| 砂地与市集 | 稀疏灌木、脚印、普通遮棚、果箱与折叠篷布；不把每处安排成广告摄影 |
| 海港与海岸 | 工作渔船、实用码头、正常海色、简单栈道与海堤；保留自然海浪和普通远岸 |
| 田野、夜街与露营 | 农路、围栏、普通路灯、朴素帐布、实用营灯；星空不强加银河与巨大天体 |

全部出场人物仍为女性，衣着继续贴近白绮的白／深紫黑／细金边、裙装、白色腿部服装和紫色鞋靴；真人不露脸。二维背影和绘制周边保留角色风格，环境改为可信的摄影质感。O／I 镜不增加真人，周边尺寸与所在支撑关系保持合理。

新图使用内置 `image_gen.imagegen`，保存于 [production-v3-realism-001](../assets/generated/production-v3-realism-001/)。每次请求与所有结果都保留，包括生成器误加人物的废选版本；旧批次保留在原目录。v2 已下载视频源片与完整请求也保留，状态标为美术修订前版本。

实际选图以 [production-plan-v4.json](../production-plan-v4.json) 为准，最终选片与修订链见[最终合成计划](../final-assembly-plan-v4.json)及[制作记录](production-v3.md)。视频每次只上传该镜完整场景图作为参考；周边母版用于图像生成及审阅。仍使用 Ref2VA、8 步，源片 832×480／24fps，最终上采样并统一为 1920×1080／30fps。计划与新素材重新审核后再正式渲染。
