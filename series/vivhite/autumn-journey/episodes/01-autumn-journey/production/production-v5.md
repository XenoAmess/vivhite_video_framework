# 1344×768 重生成与逐镜 2K 制作记录

当前为制作中，尚未交付这两版成片。导演稿为 `director-v5.md`：49 镜、196 秒、5880 个最终帧，每镜 2–5 秒；S20A 与 S20B 各 5 秒。已交付的 v3、v4 影片和全部旧稿保留。

## 实际模型与计时

- 客户端 ZIP、全部说明文档和实时 OpenAPI 已下载留档，ZIP 指纹见 `api-client-contract-v1.json`。
- 768P 使用 `http://192.168.1.11:8001/v1` 的 `fasth3-omni-bf16`，1344×768、Ref2VA、8 步。运行前检查实际 `/models` 返回 `decoder_layers=36`，并保存完整响应。
- 当前 OpenAPI 的 `task` 固定为 `ref2va`，没有独立首帧锁定参数。场景图作为构图与外观参考，提示词要求保留起始构图；不宣称接口提供严格锁定首帧的图生视频模式。
- 首三次真实推理耗时为 744.87、799.03、796.82 秒，平均每段 780.24 秒，约 13 分钟。生成完成与内容通过分别计数。
- 768P 实际完成、审阅及交付后，每段通过审核的完整 5 秒源片分别调用 `http://192.168.1.11:8002/v1/videos/regenerations`，模型 `open-h3-2k`、2560×1440、`sampler=up3`、种子 1234。
- 2K 接口按服务端文档使用本地 NVlabs/Sana 替代重生成路线，并非尚未就绪的完整 MiniMax H3。两阶段共享 GPU；2K 耗时仍以文档约 1500 秒／段估算，首批项目实际结果出来后重新计时。

预计交付窗口记录在 `schedule-768p-2k-v2.json`；开工前的 v1 估算保留。其他队列任务、停机和内容返工会影响窗口。

## 片段验收与片尾返工

首轮生成位于仓库同级 `vivhite-analysis-output/vivhite/autumn-journey/production-v5-bf16-768p-001/`，实际请求对应原计划 `production-plan-v5-bf16-768p.json`。

S15 与 S20A 已查看各自全部 120 个原生源帧、时序拼图和面部候选，实际通过人物数量、不露脸、女性服装、动作及周边行为检查。S20A 实际镜头先略靠近再后退，此观察已记录。它们以相同 SHA-256 复用于第二轮；不是沿用旧版 832×480 的源片。

S48 凭空生成无关巨熊与前景花，拒收。已核对实际上传的图片及运动参考，两者均没有这些物件。原始失败影片、请求、日志、全部源帧拼图及候选图完整保留，拒收记录见 `rejected-S48-v5-001.json`。它不进入成片或 2K 输入。

当前请求采用 `production-plan-v5-bf16-768p-r2.json`：逐场景描述实际可见元素，纯风景镜头不再带入无关周边名词；两个通过片段的请求内容不变。第二轮使用独立目录 `production-v5-bf16-768p-002/`，先重做 S48，再继续其余镜头。提示词修订是否解决问题以实际输出为准。

## 中间材料与恢复

全部生成美术图、被拒图、检查 PNG 和查看用 JPEG 都保存在本期 `assets/generated/` 并提交 Git；`image-inventory-v5-768p.json` 是制作中的指纹快照，包含历史版本。公开收据仅保存角色版本绑定和两项审核结论，具体人格审阅依据在指定私有角色库。

大型视频、音频和完整运行材料保存在仓库同级 `vivhite-analysis-output/vivhite/autumn-journey/`，不会因提交 Git 自动传到其他机器：

- `client-packages/`：原客户端 ZIP、解压文档、实时 OpenAPI 及服务端验收元数据。
- 各 `production-*/engine/`：本次实际使用的生成代码快照及指纹。
- `motion-reference/`：实际传入的已审阅运动参考；原始裁切前版本另留档。
- `requests/`、`uploads/`、`jobs/`、`logs/`、`metadata/`：完整请求、上传映射、服务端 ID、每次状态响应、服务端日志及运行配置。
- `sources-raw/`：服务端原始输出，保留原有音轨及帧对齐尾部；`sources/`：独立的精确 120 帧／24fps、无音轨 5 秒源片。
- `clip-inspection/`、`clip-decisions.json`：全源片机器检查与实际助手逐帧结论，二者分别记录。
- `soundtrack.wav` 及收据：196 秒无语音原创程序器乐与环境声；成片不混入未经采用的模型原生音轨。

后续每阶段的标准化片段、拼接画面、标题文件、完整影片和验收记录也在对应运行目录保留。更换机器时同时复制整个外部运行根目录、私有角色库及原角色 ZIP；仅拉取公开仓库不能恢复大型媒体。完整请求和服务端任务 ID 可用于恢复当前持久队列，不盲目重提状态不明的 POST。

检测结果不会自动放行。每个实际采用的完整 5 秒源片均须逐帧审阅；768P、2K 分别检查。正式合成还须绑定实际视频、音频、标题和最终计划，通过人格一致性与信息披露审核，并完成全片解码和时间轴检查。技术成功或选帧不代表人工看过完整影片。
