# 本次生成图片

按用户要求，本次 imagegen 生成的全部图片保存在项目内并提交 Git，包括母版、场景参考图和未选用的修订前版本。原始 PNG 不覆盖、不删除；同一镜头以 `v1/v2/...` 区分。提示词在 `prompts/`，物件母版在 `masters/`，逐镜参考图在 `scenes/`。

这些是实际生成图片，不是已完成视频。`production-plan-v2.json` 决定当前镜头采用哪个版本；没有被计划引用的图片仍保留。来源 ZIP 及其原图仍在仓库外，避免把原始截图版式混入生成资产。

图片由内置 `image_gen.imagegen` 生成。部分透明材质同时具有半透明片材和反射，需在实际场景中检查，不能把 PNG 的 alpha 通道当作真实材质已经完全合格。

视频、模型请求与渲染缓存放在仓库外独立运行目录。当前远端 FastH3 的技术校准失败记录见后续制作记录；不能将这些图片合成静态轮播放作任务成片。
