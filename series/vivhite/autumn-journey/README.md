# 白绮／秋日旅程

本目录是内容子项目，沿用“系列／课题／期”的组织方式。

当前交付为[v10原生768P修订版](https://github.com/XenoAmess/vivhite_video_framework/releases/tag/autumn-journey-v10-768p-20261118)：1344×768、48镜、205秒／6150帧。仅重做00:00–00:04的S01，以左手自然反手捏住窗帘，手背朝镜头、掌心朝布帘与玻璃，腕部与左臂连接连贯。用户拒收的翻掌候选不采用。其余47镜源片、全部镜头时长／起点、音乐、字幕和原生14秒片尾均与v9一致。实际动作范围及检查限制见[v10记录](episodes/01-autumn-journey/production/production-v10-left-hand-768p.md)和[交付计划](episodes/01-autumn-journey/delivery-plan-v10-768p.json)。全部候选与检查图保存在项目并入Git，见[图片清单](episodes/01-autumn-journey/production/image-inventory-v10-768p.json)；[v9 Release](https://github.com/XenoAmess/vivhite_video_framework/releases/tag/autumn-journey-v9-768p-20261118)及所有旧版本保留。

历史[导演案 v7](episodes/01-autumn-journey/director-v7.md)以无对白的多地点旅行蒙太奇展示白绮在多彩世界中的自由旅行；48镜、201秒，S20为一个连续10秒高山湖长镜，S48片尾也为10秒，其余46镜2–5秒。片尾完全复用片头中英文标题，再缓慢浮现“献给世界上最可爱的你”。BF16 FastH3、36层解码器制作的原生1344×768素材组成影片，[制作与审核记录](episodes/01-autumn-journey/production/production-v7-768p.md)区分完整源帧、编码对照和人工验收。全部2K任务已停止，不自动恢复；旧版与中间材料保留。真实感人物以手、衣袖、腿脚等不露脸局部，与白绮贴纸、玩偶、周边及意象同框；场景保留普通世界的天气、植被、日常设施和使用痕迹。

制作补充：所有出场人物均为女性，女性化服装贴近白绮设定图；静默、不露脸与短镜头要求适用于成片全部帧。原图中没有的无关人员，即使不露脸也拒收。

当前后续路线仅为[原始768P与原生4K](../../../docs/local-video-768p-4k.md)，不新建2K任务；[v11原生4K](episodes/01-autumn-journey/production/production-v11-native-4k.md)已经开始生成，采用[独立守护与直接看护](../../../docs/autumn-journey-background-rendering.md)，实际画面结论见[阶段审计](episodes/01-autumn-journey/production/quality-audit-v11-4k.md)。当前[导演稿v10](episodes/01-autumn-journey/director-v10.md)仅重做S01，其余47镜相同源片全部复用，包括v9修订后的S44/S47。第五轮14秒片尾保持开阔海岸、没有新增前景树木；用户取消减速后保留原生蝶翼，两份局部减速候选留档但不入片。片尾入片14秒，前47镜共191秒且全部时长不变，详见[工作流策略](episodes/01-autumn-journey/production/workflow-policy.json)和[v10记录](episodes/01-autumn-journey/production/production-v10-left-hand-768p.md)。第三轮15秒显存失败与第四轮树木拒收均保留历史。
