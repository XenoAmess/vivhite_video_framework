# 白绮／秋日旅程

本目录是内容子项目，沿用“系列／课题／期”的组织方式。

当前导演案为 v3：以无对白的多地点旅行蒙太奇展示白绮在多彩世界中的自由旅行；48 镜、单镜 2–10 秒，排练总长 3 分 22 秒。真实感人物以手、衣袖、腿脚等不露脸局部，与白绮贴纸、玩偶、周边及意象同框。按用户反馈，42 镜环境已重做为更接近实拍的普通世界，保留自然天气、合理植被与日常设施。

制作补充：所有出场人物均为女性，女性化服装贴近白绮设定图；静默、不露脸与短镜头要求继续适用。
