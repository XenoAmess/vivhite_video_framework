以下6组图均由内置 **imagegen** 实际生成，供用户审阅后选择形象。它们是拟制设计与场景概念，尚未生产实物，也尚未渲染视频。

| 01 | 标准比例正面、侧向与背面设定 | [角色三视图](01-character-turnaround.png)，1536×1024 |
| 02 | 贴纸、徽章、挂件与玩偶的Q版身份 | [透明底Q版母版](02-chibi-master.png)，1199×1312，RGBA真透明 |

角色身份以本轮01、02为暂定母版，周边和入景沿用同一蓝发、蓝色睁眼、鲸鳍、鲸尾及深蓝白女仆装；用户外观审阅仍待进行。03将二维形象转为绒布与刺绣，并非原图像素直接印到布上。04、05是材质和产品组合概念，不是可直接送印的刀模／色彩打样文件；正式视频首帧仍需按每镜构图另做。

6次生成的全部原始PNG均保留。06原生图比例已是7:4，仅使用FFmpeg Lanczos缩小到1344×768，没有裁切、局部修图、改色或新增创作元素；导出图另存。02已实际检查alpha通道包含0与255，其余图保留普通背景。

六张原始图均已通过工具输出实际查看，另打开并查看了06的768P导出图。检查角色身份、眼睛、服装、道具材质、印花明度和场景中的人员；这只是助手对静态概念图的审阅，不是用户审美通过，也不是未来视频的时序验收。

全部实际提示词、输入顺序和透明参数见[generation-requests.json](generation-requests.json)，逐步请求亦保存在`requests/`。检索来源见[视觉研究](../../../visual-research.md)，图片尺寸与指纹见[manifest.json](manifest.json)。生成结果保存在本项目并提交Git，默认imagegen输出副本也保留。
