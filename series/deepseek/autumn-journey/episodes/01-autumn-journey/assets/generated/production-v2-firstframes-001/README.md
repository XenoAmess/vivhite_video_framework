# v2返修图像与检查证据

使用内置imagegen重新绘制S16后方上楼首帧、S10／S23／S34／S37的正确鲸尾，以及S40无贴纸夜车背景和完整透明纸贴。`originals/`保存全部生成原件，`scenes/`保存供本地模型／合成实际使用的尺寸规范化版本，`results/`记录指纹与裁切缩放；不覆盖v1图像。

尾巴由一个相连尾柄在末端分成左右两叶，没有分叉后继续伸出的第三根竖刺。楼梯从后方看鞋跟，脚尖朝上坡。印花与周边蓝眼保持睁开，不做自主动画，光照服从场景。

`review/`中的图片只来自实际源片解码、裁切或检查图册，不是新生成的替换画面。检查工具输出不代表助手已经看过，是否采用由独立源片审核记录决定。失败候选及其图像同样保留。
