# 视频系列

创作材料按“系列 → 课题 → 多期”存放。`video-maker` 与 `video-analyzer` 保存可复用的程序和模块文档；具体视频的选题、分析、导演稿与制作计划归入本目录，不按处理模块分散。

- [数学教育系列](math-education/README.md)：用可操作的数学图形解释问题、展示推导与证明。

```text
series/
  math-education/                 系列
    inversion-count/             课题
      topic.json                 三期目录、范围与角色 ID
      episodes/
        01-sliding-puzzle/       第一期：滑块拼图与奇偶判别器
        02-rectangle-proof/      第二期：完整矩形棋盘的充分性证明
        03-wilson-theorem/       第三期：Wilson 一般图定理的完整证明
```

每期通过 `episode.json` 标识系列、课题、期号、角色 ID 与导演稿位置。跨期复用的数学定义、证明资料和验证工具放在课题内；某期专用的分析、稿件与计划放在该期内。大型原视频、配音、成片、模型和缓存仍保存在仓库外。

角色的完整人格档案存放在独立私有仓库。公开项目只引用角色 ID；创作与复审必须执行[角色参与及文案审核规约](../docs/character-workflow.md)，不在此建立公开人格副本。

旧案例目录已直接移动到新结构，不保留兼容入口。已交付视频的历史 JSON 快照保留原始字节，其中捕获时的路径属于历史来源记录；重新执行时使用当前脚本和本目录入口。
